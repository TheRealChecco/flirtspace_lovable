# FlirtSpace

Create a modern web application for an AI companion chat platform.

The goal is to build an MVP of a premium conversational platform where users can discover virtual AI characters and have personalized conversations.

Design style:

- Modern startup SaaS aesthetic

- Premium, elegant and minimal design

- Dark theme with black, deep purple and soft gradients

- Smooth animations

- Mobile-first responsive design

- Similar quality level to modern AI applications

Create the following pages:

1. Landing page:

- Hero section with a strong headline:

  "Meet your personalized AI companions"

- Short description explaining that users can chat with unique AI personalities anytime.

- Primary CTA button: "Start chatting"

- Secondary CTA: "Explore characters"

Include:

- Featured AI characters section

- Benefits section:

  - Personalized conversations

  - Unique personalities

  - Available anytime

  - Private and secure

- Pricing preview section

- FAQ section

- Footer with links

2. Character marketplace page:

Create a grid of AI characters.

Each character card should include:

- Profile image placeholder

- Name

- Short personality description

- Categories/tags

- Button "Start conversation"

Example characters:

- Romantic companion

- Funny friend

- Mystery personality

- Fantasy character

- Professional mentor

3. Chat interface page:

Create a realistic chat UI.

Include:

- Character profile at the top

- Conversation area

- Message bubbles

- Typing indicator

- Text input box

- Send button

- Credits balance indicator

The chat should look like a premium messaging application.

4. User dashboard:

Create a user profile area with:

- Account information

- Conversation history

- Favorite characters

- Credits balance

- Subscription status

5. Pricing page:

Create a simple credit-based payment model:

- Starter package

- Premium package

- VIP package

Use placeholders for Stripe integration.

Technical requirements:

- Build using React and modern components.

- Use reusable components.

- Prepare the structure for future integration with:

  - Supabase authentication

  - Supabase database

  - AI API integration

  - Stripe payments

- Keep the code clean and scalable.

Do not create a simple landing page only. Build a complete MVP structure that can evolve into a real SaaS platform.
